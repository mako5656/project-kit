# コミットメッセージ・ブランチ名の書き方

コミットメッセージ・ブランチ名・プルリクエストのタイトルは、同じ種類（プレフィックス）を使います。種類を増やす・変える場合はこのファイルだけを更新します。

## 種類（type）

| 種類 | 説明 |
|---|---|
| build | ビルドシステムや外部依存関係に影響する変更 |
| ci | CI構成ファイルやスクリプトの変更 |
| docs | ドキュメントのみの変更 |
| feat | 新しい機能の追加 |
| fix | バグ修正 |
| refactor | バグ修正や機能追加を伴わないコードのリファクタリング |
| test | テストの追加や既存テストの修正 |
| chore | その他の雑務的な変更 |

## コミットメッセージ

形式: `<種類>: <変更の要約>`

例:
- `feat: 会員登録にメール確認を追加する`
- `fix: 月末の請求日がずれる不具合を修正する`
- `chore: 依存ライブラリを更新する`

## ブランチ名

形式: `<種類>/<内容（英語・kebab-case）>`

例:
- `feat/member-email-confirmation`
- `fix/billing-month-end`

## プルリクエスト

タイトルはコミットメッセージと同じ形式にします。
